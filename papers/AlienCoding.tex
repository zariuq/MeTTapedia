\begin{abstract}
We develop a reproducible empirical program around ``alien coding'': learning to propose
small programs that reproduce integer sequences, checking those programs independently,
and returning verified discoveries to the learner.  The program has two deliberately
different experimental instruments.  A recursive tree neural network coupled to guided
tree search provides a compact causal testbed for changing the learning rule while holding
the architecture and search fixed.  A bidirectional recurrent sequence-to-sequence model
with attention is the higher-capacity mainline for studying learned program priors and
multi-generation feedback.  On the tree testbed, an upstream backpropagation result is
replicated, a fixed-step state-based predictive-coding variant reaches 93\% of the one-generation
backpropagation yield at roughly ten times the training cost, and a deterministic paired
three-world campaign tests whether that gap compounds over generations.  The common
generation-4 snapshot is compounding-shaped, with a paired geometric mean yield ratio of
0.648, but the registered verdict is reserved for generation 5.  On the recurrent model,
two independently trained historical-port runs add 3,140 and 3,080 checker-verified
sequences; a fidelity-corrected reference and discriminating implementation oracles are
now available, while its preregistered bounded check remains open after a checker-method
substitution and a target-association serialization defect were found.  We separate
verified discovery, target-conditioned synthesis, and unconditional hindsight coverage;
report resource costs in human units; and specify the unrolled-graph oracles required
before applying predictive coding to an attention-based recurrent model.
\end{abstract}

\section{The empirical question}
\label{sec:intro}

An integer-sequence synthesizer receives a finite prefix of a sequence and proposes a
program in a small combinator language.  This setting follows the ``alien coding'' program
of Gauthier, Olsak, and Urban~\cite{aliencoding}.  A separate evaluator then asks whether
the program reproduces a target sequence.  The central scientific object is not a single
neural model, but the closed loop
\[
  \text{verified corpus}
  \longrightarrow \text{learner}
  \longrightarrow \text{proposal process}
  \longrightarrow \text{independent checker}
  \longrightarrow \text{verified corpus}.
\]
This loop supports three questions that should not be collapsed into one:

\begin{enumerate}
  \item Does learning ignite useful program search relative to an untrained or random
        proposal process?
  \item Given fixed architecture and search, how does the learning rule change proposal
        quality, cost, and multi-generation feedback?
  \item Does a sequence-to-sequence model use the requested sequence, or does it merely
        learn a broadly useful unconditional program prior?
\end{enumerate}

The verified language, recognizer, synthesis contracts, leakage-safe corpus view, and
graded extensional and intensional measurements are treated in the companion account
\emph{OEIS Program Synthesis, Verified Semantics, and Graded Similarity}~\cite{oeisaccount}.
That account deliberately contributes a verified and measured object layer rather than
another synthesizer.  The present paper owns the empirical systems, interventions,
longitudinal estimands, and resource measurements.  Keeping the two accounts separate
prevents results from different architectures and corpora from being mistaken for claims
about the verified semantics itself.

\subsection{Evidence discipline}

Every result below is typed by its evidence:

\begin{itemize}
  \item A \emph{verified discovery} is a distinct sequence identifier returned by the
        independent program checker beyond a frozen baseline set.  Verification means
        agreement on the frozen finite 20-term observation; it does not establish identity
        of the corresponding infinite sequences.
  \item A \emph{conditional target hit} requires at least one canonical program harvested
        from a proposal occurrence requested for target $T$ to compute $T$.  A
        \emph{direct-full hit} uses the program represented by the complete normalized
        emission, whereas a \emph{harvested-prefix hit} uses a proper harvested prefix.
        The two target sets can overlap, and their union is the conditional-hit set.  The
        target--proposal--origin association must survive parsing and checking.
  \item \emph{Hindsight coverage} checks a proposal multiset against all sequences without
        regard to the target that elicited each proposal.  It measures the usefulness of a
        program prior, not sequence conditioning.
  \item A replicated claim requires at least two independent training seeds.  A paired
        longitudinal claim treats independent seed-worlds, not programs or search nodes,
        as the inferential units.
\end{itemize}

Interpretations and stopping rules are fixed before their endpoint is observed.  Inputs,
source, configuration, logs, outputs, and completion records are content-manifested.
Retries create new attempts rather than overwriting evidence.  These rules matter because
program checking and search are long-running stateful computations: a partial check must
never become a zero, and an operational restart must never silently become a new scientific
condition.

\section{A tree-neural causal testbed}
\label{sec:tree}

The first instrument is the recursive tree neural network and guided search used by the
QSynt line of work~\cite{gauthier2023}.  Each operator owns a shared affine map.  A program
DAG is evaluated bottom-up to produce node embeddings; policy heads predict search actions.
There are no value heads in the configurations studied here, so the learned policy prior
is the only neural guidance supplied to search.

\subsection{Upstream replication and one-generation ignition}

The upstream pipeline was rebuilt with its Standard ML search, C/BLAS tree learner, and
HOL-based checker.  At the small replication setting, a random generation-0 search found
861 sequences and one 100-epoch backpropagation training round followed by guided search
raised the cumulative count to 4,956, a $5.76\times$ ignition.  A second seed produced
$863\rightarrow4{,}772$.  Thus the two-seed mean guided yield is 4,864, with the two runs
within 1.9\% of that mean.  These runs establish an operational and scientific baseline;
they are not compared numerically with the recurrent model, whose language, initial corpus,
proposal budget, and checker path differ.

\subsection{Exact learning-rule intervention}
\label{sec:tree-rule}

For a hidden node $n$, let $z_n$ be its post-activation latent and let
$f_n(z_{\mathrm{ch}(n)};\theta_{o(n)})$ be the prediction made by the matrix shared by
operator $o(n)$.  For a policy head $h$, let $g_h(z;\theta_h)$ be its tanh output and
$t_h$ its soft target.  The implemented predictive-coding energy is represented by
\[
  F(z,\theta)
  = \frac{1}{2}\sum_h \lVert t_h-g_h(z;\theta_h)\rVert_2^2
    + \frac{\beta}{2}\sum_{n\in\mathcal H}
       \lVert z_n-f_n(z_{\mathrm{ch}(n)};\theta_{o(n)})\rVert_2^2 .
\]
This is a finite-step, digitally simulated instance of state-based predictive coding
(sPC): the inferred variables are node states, and the inference signal moves through
local residual factors.  All tree results in this paper are claims about this exact sPC
implementation, not about predictive coding as a whole.  Recent approaches attack deep
sPC's digital scaling problem by changing initialization and residual scaling
($\mu$PC)~\cite{innocenti2025mupc} or by reparameterizing inference in terms of prediction
errors (ePC)~\cite{goemaere2026epc}; neither method is part of the tree campaign.
Latents are initialized to the ordinary forward activations.  With weights fixed, the
implementation performs $K$ simultaneous latent-gradient steps
\[
  z_n \leftarrow z_n-\eta_z\nabla_{z_n}F .
\]
It then performs one local outer-product update per node.  The selected arm, denoted PC32,
fixes $K=32$, $\eta_z=0.1$, and $\beta=1$.  The BP arm uses the existing reverse pass.
Both arms use batch-one stochastic updates and 100 epochs.  The exact outer learning-rate
schedule is $8$, $4$, $2$, and $10^{-4}$ on epoch blocks 0--24, 25--49, 50--74, and
75--99, respectively.  Each parameter update is clipped to $[-4,4]$; latent gradients are
not clipped.

The label \emph{state-based predictive-coding variant} is important.  Settling itself holds all weights
fixed.  After settling, however, the implementation visits node occurrences in reverse
order, recomputes each local residual from the live shared operator matrix, and immediately
mutates that matrix.  If an operator occurs twice, the later occurrence observes the first
occurrence's update.  BP computes its reverse signals before its update loop, so its
per-occurrence contributions are based on fixed forward values.  The registered campaign
therefore tests this exact order-dependent PC32 implementation.  A future exact-schedule
control must accumulate all tied-operator contributions under one fixed parameter state
and apply them once.

The PC path was checked against independent numerical goldens on a two-node case and on a
shared multi-parent DAG; deliberately broken variants fail those comparisons.  The BP path
remains a separately selected branch.  These implementation oracles establish agreement
with the specified local update, not equivalence to BP.

\subsection{Deterministic paired multi-generation campaign}
\label{sec:tree-protocol}

The pilot runs used clock-seeded search and training shuffles, so they could not answer a
multi-generation causal question.  The paired campaign replaces every such draw with a
recorded deterministic stream:

\begin{itemize}
  \item Three independent worlds use master seeds 26,071,001--26,071,003.
  \item A domain-separated SHA-256 derivation supplies all controller, target-job, weight,
        and epoch-order seeds.  Every derived seed lies in the accepted 31-bit range.
  \item Within a world, BP and PC32 begin from byte-identical generation-0 corpora, model
        parameters, and epoch order.  Their 50 search jobs use identical
        $(\text{job},\text{target},\text{seed})$ ledgers and reset search caches per job.
  \item After generation 1, each arm trains on its own cumulative verified corpus.  The
        keyed sampling rule is shared, but byte-identical batches would be impossible and
        scientifically wrong once the corpora diverge.
  \item BP-first and PC-first order alternates, and only one trajectory runs at a time.
        Each phase writes a manifest and an independently checkable completion record in a
        fresh attempt root.
\end{itemize}

The medium setting uses 128-dimensional node states, four search workers, 50 targets per
generation, and a nominal 200 target-seconds per target: nominally 10,000 target-seconds,
or 2.78 target-hours, per search arm.  One job overshot to 247.46 seconds, so 10,000 is a
target budget rather than an exact realized total.  Successful search wall time is
43.52--44.54 minutes because the four jobs run in parallel with orchestration overhead.

Let $C_{s,a,g}$ be the cumulative number of distinct verified sequences in world $s$, arm
$a$, and guided generation $g$.  The primary paired ratio and change are
\[
  R_{s,g}=\frac{C_{s,\pc,g}}{C_{s,\bp,g}},
  \qquad
  T_{s,G}=R_{s,G}-R_{s,1}.
\]
For each world we also fit the ordinary least-squares slope of $R_{s,g}$ over
$g=1,\ldots,G$.  The endpoint summary is the geometric mean of the three $R_{s,G}$ values
with a two-sided 90\% $t$ interval on log ratios, treating worlds as the three inferential
units.

At $G=5$, the frozen classifier uses the following precedence order; the first satisfied
label is reported:
\begin{itemize}
  \item \emph{compounds}: median $T_{s,5}\leq-0.03$ and all three slopes are non-positive;
  \item \emph{closes to parity}: all slopes are non-negative and the endpoint interval lies
        in $[0.97,1.03]$;
  \item \emph{closes materially}: median $T_{s,5}\geq0.03$ and all slopes are non-negative;
  \item \emph{persists}: median $T_{s,5}$ lies within $\pm0.03$ and parity equivalence is
        not established;
  \item \emph{mixed/inconclusive}: none of the above.
\end{itemize}
These labels describe the total effect of a learning rule inside its own feedback loop.
They do not isolate a same-corpus gradient effect after generation 1.

\section{The recurrent sequence-to-sequence mainline}
\label{sec:nmt}

The mainline architecture maps a tokenized sequence prefix to a program token sequence.
It has a one-layer bidirectional LSTM encoder, two 512-unit decoder LSTM layers with input
feeding, and scaled Luong attention.  Beam search proposes programs, while the same
independent evaluator used by the upstream synthesis system determines which sequences
they compute.  Unlike the tree testbed, this model can learn both a conditional mapping
from input sequences and an unconditional prior over syntactically useful programs.

\subsection{Historical PyTorch port: real effect, bounded interpretation}

The first modern port, retained as version 0, trained two seeds for 12,000 SGD steps on the
3,771-sequence base corpus.  Full decodes followed by whole-corpus program checking yielded
3,140 and 3,080 new distinct sequences.  The two discovery sets overlap on 2,527 sequences
and add 3,693 distinct sequences in union.  These counts have been recomputed from the
checker outputs and set differences.

An untrained network produced zero new sequences on a complete post-hoc assay of 2,000
targets at beam 240, compared with 746 and 780 for the two trained models under the same
non-harvesting check.  This is strong two-seed evidence that training learns program syntax
and a useful proposal distribution.  It is not closure of the original full-target,
prefix-harvesting control, which did not complete; and no randomized target-association
control was run.  The supported claim is a replicated learned-program-prior effect, not yet
a sequence-conditioning claim.

Source audit also found that version 0 was not a faithful reference implementation.  It
applied the forget bias to both PyTorch LSTM bias vectors, giving an initial effective
offset of two and 8,192 extra trainable bias parameters; shared encoder input dropout
between directions; omitted dropout from the previous-attention and upper-decoder inputs;
and decoded to length 32 rather than the historical horizon of 280.  The version-0
evidence remains valid for that exact model but is not used as the BP reference for a
future PC comparison.

\subsection{Fidelity-corrected version 1}
\label{sec:nmt-v1}

Version 1 uses a single effective trainable LSTM bias, initializes all gate biases to zero,
adds the forget offset once, and freezes the duplicate recurrent bias at zero.  Its
trainable parameter count is 10,781,697.  It applies independent input dropout to the two
encoder directions, to the complete decoder input-feeding vector, and to the second
decoder layer's input.  The decode horizon is 280 and the beam is 240.

Five retained oracles test overfitting 32 examples, beam-score agreement, attention masking,
EOS termination, and deterministic logits.  Each has a positive case and a deliberately
broken negative case; all transcripts are bound by one SHA-256 manifest.  Two version-1
seeds completed the same 12,000-step recipe in 17.4 and 16.5 minutes.  On a frozen
21,061-target grid, their beam decodes took 168 and 162 seconds; the untrained decode took
1,058 seconds.  The calibrated decode peak was 20.3 GiB of GPU memory.

The complete non-harvesting check produced the provisional counts in
Table~\ref{tab:nmtv1}.  They strongly suggest replicated ignition, but they do not close
the preregistration.

Two audit findings prevent a stronger statement.  First, the preregistration fixed a
prefix-harvesting checker inside immutable content-addressed attempts, whereas the completed
run substituted a non-harvesting checker, reused mutable work roots, and wrote no completion
record.  The three arms were checked consistently, but under a different method and weaker
provenance discipline.  Second, the target-association analysis serialized a set of
multi-token canonical programs by joining them with spaces and reconstructed the set by
splitting on spaces.  It therefore compared complete sidecar programs against individual
tokens.  The reported conditional, direct-full, harvested-prefix, and
randomized-association numbers are invalid.  The registered target-conditioning endpoint
remains unresolved.

The content-addressed broker in Section~\ref{sec:broker} is consequently a scientific
requirement, not merely operational cleanup.  Its implementation and lightweight unit
suite exist, but the broker remains under validation until a live differential oracle
agrees with the stock HOL checker and the complete prefix-harvesting N4 recheck finishes
successfully.  Until that recheck is complete, version 1 is a fidelity-corrected implementation reference
with provisional ignition evidence.

\subsection{Content-addressed proposal and check broker}
\label{sec:broker}

The broker keeps three identities separate.  A \emph{proposal-occurrence ID} binds the
model and decode identities to the sidecar source-line number and raw-row hash.  A distinct
\emph{normalized-emission ID} identifies the whitespace-normalized reverse-order string,
independent of how many proposal occurrences emitted it.  Prefix harvesting then produces
one or more \emph{canonical-program IDs}, each derived from an unambiguous canonical
postfix program.  Explicit relations connect proposal occurrences to emissions, emissions
to harvested programs and origin kinds, and programs to checker coverage.  Programs are
never serialized by an ambiguous token delimiter.

A broker request hashes the canonical candidates, target and sidecar slices, model,
checker source and configuration, environment, and baseline solution set.  Each request
has immutable numbered attempts, and each chunk has its own isolated checker root.
Completion requires all expected chunks, their output hashes, and aggregate invariants.
Only then is a final completion object written and its digest stored in the attempt's
\texttt{DONE} record.  A retry creates a new attempt and may adopt a prior chunk only after
validating its request and completion hashes.  No checker configuration or experiment
directory is edited in place.

This representation makes four related measurements explicit.  Writing $p\leadsto q$ when
canonical program $q$ was harvested from proposal occurrence $p$, and
$\operatorname{full}(p,q)$ when it represents the complete normalized emission,
\[
\begin{split}
\text{conditional hits}
  &= \bigl|\{T:\exists p,q,\ \operatorname{requested}(p)=T
                   \land p\leadsto q \land \operatorname{computes}(q,T)\}\bigr|,\\
\text{direct-full hits}
  &= \bigl|\{T:\exists p,q,\ \operatorname{requested}(p)=T
                   \land p\leadsto q \land \operatorname{full}(p,q)
                   \land \operatorname{computes}(q,T)\}\bigr|,\\
\text{harvested-prefix hits}
  &= \bigl|\{T:\exists p,q,\ \operatorname{requested}(p)=T
                   \land p\leadsto q \land \neg\operatorname{full}(p,q)
                   \land \operatorname{computes}(q,T)\}\bigr|,\\
\text{hindsight coverage}
  &= \bigl|\{T:\exists q,\ \operatorname{computes}(q,T)\}\bigr|.
\end{split}
\]
The direct-full and harvested-prefix target sets may overlap; their union is exactly the
conditional-hit set.  A keyed permutation of the $\operatorname{requested}$ relation
supplies C2 without changing the proposal multiset or hindsight coverage, and C2 reports
the same conditional, direct-full, and harvested-prefix sets together with their overlap.

\subsection{Generation-2 loop gain and multi-generation PC--BP}
\label{sec:nmt-multigen}

The first prospective version-1 longitudinal experiment separates loop gain from learning
rule comparison.  Independent worlds begin from the same base corpus.  Within each world,
a feedback arm adds only broker-verified generation-1 discoveries to a canonically ordered
cumulative ledger; a no-feedback arm retrains from the unchanged base corpus.  The pair
shares its generation-2 initialization, optimizer-update budget, batching rule, target
grid, beam, and checker.  Actual example and token exposures are reported because equal
optimizer steps are not equal data exposure when corpora differ.

The preserved version-0 generation-2 decodes are useful only as a broker load test.  Their
feedback corpus pooled worlds, changed multiplicities, omitted rows without a manifested
rule, and exposed the treatment to 5.29\% more examples under the nominally equal update
count.  A no-new-training-or-decode-cost broker recheck can be reported as a descriptive
pilot, but checking still consumes compute and cannot repair that causal design after the
fact.

Only after the recurrent-PC gates in Section~\ref{sec:recurrent-pc} pass does the mainline

matched wall time is a separate secondary question.

\section{Predictive coding on an attention-based recurrent model}
\label{sec:recurrent-pc}

Applying the tree PC update directly to a bidirectional LSTM would be neither a faithful
recurrent implementation nor a fair BP comparison.  Bidirectionality, LSTM multiplicative
gates, a loss at every decoder step, attention branches, input feeding, masking, unequal
paths, and parameters tied over time all matter.

\subsection{Explicit unrolled computation graph}

The first implementation exposes latent nodes for encoder forward and backward $(h,c)$ at
each source position; both decoder layers' $(h,c)$ at each target position; attention
scores, normalized attention, context, and attentional output; and token logits.  Source
tokens and teacher-forced previous target tokens are fixed.  Padding and post-EOS positions
are masked exactly as in BP.  A coarse LSTM transition is initially one differentiable
factor rather than a collection of gate-level latents.

Let $z^{\ell}_t$ be the explicit token-logit latent and let $f^{\ell}_t$ predict it from
the attentional state.  For the other latent groups $g$, the proposed energy is
\[
 F(z,\theta)
   = \sum_{t\in\mathcal M}
       \operatorname{CE}\!\left(y_t,\operatorname{softmax}(z^{\ell}_t)\right)
     + \frac{\lambda_{\ell}}{2}\sum_{t\in\mathcal M}
       \lVert z^{\ell}_t-f^{\ell}_t(\operatorname{pa}(z^{\ell}_t);\theta)\rVert_2^2
     + \frac{1}{2}\sum_{g\ne\ell} \lambda_g
       \lVert z_g-f_g(\operatorname{pa}(z_g);\theta)\rVert_2^2,
\]
where $\mathcal M$ is the unmasked token set.  Thus cross-entropy consumes the logit latent,
while a separate residual factor connects that latent to its predicted logits.  Local
automatic differentiation may provide vector--Jacobian products for individual factors,
but it must not differentiate through the $K$ inference iterations.  At each settling step
the latent leaves are detached and rebuilt; weights remain fixed.  After settling, all
contributions to recurrent, attention, embedding, and output parameters are accumulated
over times, directions, layers, and tokens before one update is applied.

\subsection{Candidate inference parameterizations}

The energy and unrolled graph are the scientific object; the numerical method used to
infer their internal variables is a separate intervention.  The direct continuation from
the tree experiment is state-based inference, which optimizes the latents $z_g$.  ePC
instead introduces an additive error for each predicted latent,
\[
  \epsilon_g = z_g-f_g(\operatorname{pa}(z_g);\theta),
  \qquad
  z_g=f_g(\operatorname{pa}(z_g);\theta)+\epsilon_g,
\]
and reconstructs the graph in topological order.  It then uses reverse-mode automatic
differentiation through that reconstructed graph to optimize all errors at once, while
retaining the local, post-inference weight rule.  For a feed-forward hierarchy this is a
bijection that preserves the energy and its set of critical points, although state-based
and error-based optimization follow different trajectories and can in principle select
different minima~\cite{goemaere2026epc}.

This makes ePC a relevant candidate for the depth-through-time problem, not an automatic
choice.  Its published evidence covers feed-forward MLP, VGG, and ResNet image classifiers;
the released core implementation is a sequential vision stack, not an attention-based
recurrent model.  Likewise, $\mu$PC demonstrates that residual parameterization can train
very deep sPC classifiers~\cite{innocenti2025mupc}, but does not establish a recurrent
attention algorithm.  We therefore compare state-based and error-based inference on the
same unrolled NMT energy before choosing a main PC arm.  Error-based inference qualifies
only if it preserves the graph and local-weight-update oracles, learns the 32-example
problem in at least two seeds, produces a demonstrably non-BP terminal update rather than
the one-step BP endpoint, and has a measured cost compatible with the paired experiment.
State-based inference remains the direct tree-comparison arm and the diagnostic for
finite-settling effects.

\subsection{P0: graph-fidelity oracle}

P0 is an oracle suite, not a training result.  On short padded and unpadded examples it must
establish:

\begin{enumerate}
  \item the unrolled forward logits, hidden and cell states, attention weights, contexts,
        and loss equal those of the fused version-1 BP model within a frozen tolerance;
  \item masked source positions receive zero attention and masked target positions
        contribute neither loss nor parameter update;
  \item repeated-time and repeated-token parameter contributions are summed under one
        frozen parameter state;
  \item the energy is finite and one sufficiently small latent step decreases it;
  \item deliberately broken direction order, cell-state recurrence, attention mask,
        input-feeding edge, EOS mask, and tied-gradient accumulation each fail a named
        negative test;
  \item state and error parameterizations give equal energy on mapped configurations,
        and zero error reconstructs the fused forward pass.
\end{enumerate}

P1 then compares one update against a numerical gradient, checks long-horizon state/error
equilibrium agreement on small tractable graphs, verifies that one-step ePC gives its
predicted scaled-BP endpoint, and requires the chosen finite-settling update to separate
measurably from BP before it can be called a PC treatment.  It also runs a short
exact-schedule control.  Published Z-IL exactness extends to a considered many-to-one recurrent network
\cite{salvatori2021}; it does not by itself establish exactness for this variable-length,
many-output biLSTM encoder--decoder with attention.  General computation-graph predictive
coding is relevant~\cite{millidge2020}, but leveling, event timing, masking, and tied
accumulation remain implementation obligations here.

\section{Stabilization experiments}
\label{sec:stabilization}

Four candidate interventions answer different questions and should remain separately named.

\begin{enumerate}
  \item \textbf{Proposal temperature} is the cheapest causal probe of the decisiveness
        hypothesis.  The tree search already renormalizes a powered prior.  The recurrent
        beam currently uses raw log-softmax scores with no temperature.  A disjoint target
        screen should freeze one temperature before a full replay.  In the NMT, temperature
        can change EOS timing, sequence ranking, and beam membership even when the
        within-prefix token order is unchanged.
  \item \textbf{Adaptive settling} should stop on normalized energy decrease and latent
        gradient norm, with minimum and maximum iteration counts and a divergence guard.
        Output entropy is an outcome diagnostic, not the Lyapunov function and not a valid
        stopping quantity.
  \item \textbf{Exact scheduling} is a correctness control.  If it reproduces BP exactly,
        it need not receive its own multi-generation campaign.  Its purpose is to validate
        graph construction, event levels, and tied-gradient accumulation.
  \item \textbf{Precision-weighted residuals} should begin with fixed, shrunk group
        precisions.  In the NMT these groups include encoder hidden/cell transitions,
        decoder hidden/cell transitions, attention/context, and the categorical output.
        Learned precisions require their normalization term and constraints that prevent
        a trivial collapse.
\end{enumerate}

These experiments distinguish stabilization of inference from calibration of the proposal
process.  A temperature intervention can improve search while leaving learning untouched;
an energy stop can reduce learning cost without changing the decoder; and an exact schedule
can validate implementation while offering no performance gain.

One of these prescriptions must be narrowed, and a second acquires a use it did not have.
The decoder recurrence is a cycle, so its settling correction solves $y-Ay=b$ for a cycle
operator $A$ fixed by where the graph is cut, and after $R$ damped steps at fraction
$\alpha$ the available geometric bound runs on $q_\alpha=(1-\alpha)+\alpha q$, where $q$
is a declared norm bound for $A$.  When only $q\ge1$ is available, that construction
merely fails to certify contraction; it does not establish that the exact damped map
expands.  The counterexample is immediate: for $A=-2I$ and $\alpha=1/3$ the norm
construction returns $4/3$ while the damped operator is exactly zero.  A genuine
no-rescue conclusion needs a directional witness---a nonzero mode with $Av=\lambda v$ and
real $\lambda\ge1$---not a norm observation.

Our coarse-cut telemetry does not supply that witness.  Latent gradients of order
$10^{7}$, transported credit plateauing at cosine $0.270$ across settling depths $32$
through $160$, and a further $26\%$ energy decrease are consistent with an expanding
cycle, and equally with large forcing, a sensitive credit readout, or non-normal
transient amplification.  Identifying which requires extracting the linearized operator
for this decoder and certifying an enclosure over an invariant region, which no amount of
training telemetry supplies.

Item~2 is nonetheless the one prescription that must change, and it changes on measured
grounds rather than on any claim about the operator.  Approaching a settling failure this
carrier recorded monotone energy descent at every accepted step while the credit direction
had already fallen to cosine $0.0008$ against the reference.  That inner product is still
positive, so the first-order term remains a reduction; its normalized alignment is only
about $8\times10^{-4}$, roughly three orders of magnitude below an aligned direction.
Without a curvature bound, an admitted-step-size certificate, and numerical and readout
error budgets, that observation does not establish robust finite-step descent: the
quadratic remainder or either error source may overwhelm the small positive margin.  For
a positive directional-curvature bound $\kappa$, the standard sufficient trust condition
is $\eta\kappa/2<\langle g,d\rangle$; that inequality was not certified here.  The
monotone energy trace therefore failed to expose the loss of alignment.  A large-gradient
guard may still detect this particular approach to failure, but neither energy decrease
nor a bare gradient norm certifies credit direction.  The admissible criterion is an
explicit alignment floor with its uncertainty charged.  Item~3 gains a purpose beyond
validating graph construction: an exact schedule
supplies the reference credit direction that such a floor is measured against, without
which the alignment gate has no denominator.  It does not by itself identify $q$ or
$\alpha$.

A finer cut remains the best-motivated repair, since it replaces long products of
transition sensitivities along the recurrence with local ones, and $q$ is a property of
that choice.  The successor arm makes that change and its median credit cosine rose from
$0.888$ to $0.9996$ over six thousand updates, with median relative credit error falling
from $0.46$ to $0.028$.  That is training-time telemetry, neither a contraction
certificate nor a behavioral endpoint.  Whether it also predicts reference-like discovery
requires the separate uniform-curvature premise under which exactly settled credit is a
positive multiple of the reference credit; the expectation that the successor lands near
its backpropagation twin is a timestamped pre-checker hypothesis, not a sealed
registration.

The checker has since answered, and the hypothesis was wrong. The successor arm produced
\emph{zero} new verified targets from $1{,}843$ unique candidates, with no direct hits and
only $16$ already-known targets covered; its matched backpropagation twin produced $240$
new targets from $2{,}787$ candidates in the same round on the same corpus. The count fell
below the predecessor's rather than approaching the twin's, so the account is refuted on
the terms it named.

The diagnosis drawn from training telemetry, before any checker result existed, is what
survived. Evaluation accuracy on that arm peaked near update $1{,}400$ and then fell by
more than half, task loss rose, and the gradient norm grew roughly fortyfold---from a
median near $22$ early to $857$ late---while credit alignment to the reference climbed
monotonically to $0.9996$. The direction converged and the magnitude diverged. For this
carrier the practical consequence is blunt: an alignment statistic cannot serve as the
health signal for a settling arm, because it quotients out precisely the coordinate that
failed, and the arm consumed its entire budget while every direction-based indicator
improved.

Two smaller corrections follow. The joint-retraining contrast on this carrier, which had
favoured retraining in earlier rounds, drew level in the latest one at $204$ against
$200$, so the retraining advantage recorded here is a measured contingency rather than a
property of the carrier. And the collateral-discovery role of this instrument is
undiminished: of the targets sealed into the latest cumulative event, the $200$
contributed by this carrier were private to it, none of them found by the higher-capacity
arms running the same corpus and the same checker.

The next experiment therefore moved the learning-rule contrast to a small module instead
of repeating whole-carrier settling.  Exact TGAD--GRU and TGAD--Transformer anchors were
frozen; only a $2{,}115$-parameter retrieval module learned, either as one feedforward pass
or as a two-state fixed-depth recurrent refinement, by backpropagation or local predictive
coding.  The program sampler selected a sequence first and then one unique verified
program for it.  A paired replay condition additionally exposed deduplicated programs
that the checker had found to solve an off-target sequence.

At $500$ updates the replay portfolios tied at $34$ new target identities.  In a separate
replication-and-extension to $2{,}500$ updates, baseline replay covered $30$ identities
and verifier-hindsight replay $32$.  Both additions occurred only under TGAD--GRU at one
of three seeds, and neither was a direct hit for the query that generated it.  All twelve
paired TGAD--Transformer comparisons had zero target-count effect.  Predictive coding's
mean main effect was $+0.125$ target and its interaction with recurrent refinement
$+0.083$, both smaller than the granularity of one target at the replication unit.  One
exclusive target, A6355, was confined to recurrent PC with hindsight replay and had two
program witnesses; it is a concrete replication candidate, not a general advantage.
The larger-budget phase was selected by registered differences at $500$ updates and used
fresh search draws, so it is not an independent confirmation of the earlier endpoint.

This local PC was numerically genuine.  Its credit remained nearly backpropagation-aligned
before AdamW, but the post-optimizer update had median cosine about $0.63$ in feedforward
modules and $0.90$ in recurrent modules.  The optimizer therefore created a scientifically
different update geometry, yet the checker endpoint remained nearly unchanged.  The
experiment also did \emph{not} test conserved retrieval credit: the proposed direct
query-edge treatment had no eligible direct receipts and changed no retrieval weight, so
it was stopped before checking and replaced by hindsight replay.  This distinction keeps
three claims separate: local PC showed no robust benefit here; hindsight replay produced
a small, concentrated collateral portfolio gain; learned query-conditioned retrieval
weights remain untested.

\section{What can and cannot be compared}

The tree and recurrent systems are complementary, not two rows in an architecture
leaderboard.  The tree testbed begins from roughly 1,600 medium-run discoveries, uses a
larger active operator profile, trains a 128-dimensional recursive model, and allocates
budgeted MCTS-like target searches.  The recurrent model begins from 3,771 baseline
sequences, emits the 14-operator target language, and uses beam search over every target or
a frozen target grid.  Absolute solution counts confound language, starting corpus,
proposal count, evaluator budget, and hardware.

The valid cross-system comparison is methodological:

\begin{itemize}
  \item the tree instrument isolates an exact learning-rule implementation and reveals how
        its proposal prior interacts with guided search;
  \item the recurrent instrument tests whether a larger learned prior ignites, conditions
        on inputs, and benefits from verified feedback;
  \item both require independent checking, target-aware identity, paired seed-worlds, and
        honest separation of discovery, conditioning, and compute.
\end{itemize}

An architecture comparison would require a separate frozen common language, baseline
corpus, target set, checker, and declared proposal/evaluator budgets.  Native wall-time
curves should still be reported separately because tree search and beam search are
intentionally different algorithms.

\section{Continuous training against joint retraining}

The original loop names this axis and leaves it qualitative.  Its \emph{continuous
training} option re-uses the previous iteration's model and trains it further on the
latest data, which is expected to be more stable and eventually trained for orders of
magnitude more steps; the alternative trains only on the latest corpus and is expected to
be less encumbered by old solutions and more focused on exploring recent
ones~\cite{aliencoding}.  Both intuitions are plausible, they predict opposite winners,
and neither is measured there.

A registered control measures it on the recurrent carrier under a fixed credit rule.  Two
observer lineages, one per carrier, were trained from the authenticated initial weights on
the frozen final cumulative corpus for the same cumulative update budget the continued
lineages had spent, then searched and checked identically, with their discoveries
quarantined from the shared corpus so the measurement cannot perturb what it measures.
This is a cleaner separation than the original description affords: the published contrast
bundles weight inheritance with corpus scope, since its from-scratch variant also narrows
to the latest data, whereas here both conditions see the same accumulated corpus and only
the weight history differs.  What remains bundled is arrival order---the retrained model
sees the whole corpus from its first update---so the estimand is offline joint retraining
against streaming continuation, and only the terminal budget comparison is free of the
retrained model's future information.

Both intuitions turn out to be correct, on different projections of the checker's relation.
Joint retraining is the better explorer: on the recurrent carrier it covers more new targets
at every measured budget---$361$ against $336$, $304$ against $215$, $228$ against $192$,
and $225$ against $202$---and its new-target yield per unique proposal is higher in every
measured cell of the experiment, by factors between $1.08$ and $1.45$.  Continuation is the
better custodian: it covers more already-known targets in seven of eight cells, by up to
$370$ targets, so total support favours it in six of eight.  Stability and exploration are
separated endpoints, and the loop's design choice determines which is bought.

The result is also carrier-dependent, which the original framing does not anticipate.  At the
terminal budget the recurrent carrier gains $+23$ new targets from retraining while the finer
Unified carrier loses $12$, an interaction of $+35$.  The earlier landmarks alternate in sign
for the Unified carrier and are uniformly positive for the recurrent one, and since their
future information favours retraining, the Unified deficit is the conservative reading and the
recurrent gain the weaker one.  One pair of training runs sampled at four budgets does not
license a population claim.

Finally, the portfolio argument of the original work is confirmed quantitatively and its
scope widened.  There the argument is made for models differing in language, objective, or
architecture; here the two models differ \emph{only} in training history, and they still
overlap remarkably little.  The Jaccard index of their new-target sets falls from $0.185$ to
$0.041$ on the recurrent carrier, so their union exceeds the better single condition by a
factor between $1.54$ and $1.82$ in all eight cells---$410$ recurrent targets at the terminal
budget against the best single $225$.  Training history alone is enough to make two otherwise
identical learners complementary, which argues for running both rather than choosing.  Because
the two draws share architecture and corpus they are positively dependent, so a
Lincoln--Petersen reading of the overlap ($2674$ and $973$ reachable targets at the terminal
budget) bounds the reachable pool from below rather than estimating it.

\section{A retrieval-adapter pilot, and why it answers little}
\label{sec:adapter-pilot}

Recorded for replication honesty; the design does not support architectural inference.

\textbf{Setup.} Fresh top-down grammar-masked backbones---a $5.24$M-parameter GRU and a
one-layer $5.44$M-parameter Transformer---were trained from scratch for $500$ updates and
then \emph{frozen}. All subsequent training ($2{,}500$ updates) modified only a
$2{,}115$-parameter adapter: a width-$32$ two-state module with two learned scalar
couplings, run either in one pass or as four damped $\tanh$ iterations, receiving retrieved
verified action traces. Four crossed factors---backbone, one-pass versus cyclic adapter,
backpropagation versus local predictive coding \emph{on the adapter only}, and whether
training-program sampling included cross-target verified solutions---over three seeds,
$126$ runs, $11.6$ summed GPU-hours.

\textbf{Results.} Every retrieval-adapter condition tied its no-memory anchor within
backbone and seed. The predictive-coding main effect on new-target count was $+0.125$
targets and its interaction with the cyclic adapter $+0.083$; post-optimizer credit cosine
to backpropagation was $\approx0.63$ (one-pass) and $\approx0.90$ (cyclic), so the rule was
operational and distinct without being useful. Including cross-target solutions in training
sampling moved the distinct-target portfolio from $30$ to $32$ and changed direct
target-conditioned success in $0$ of $24$ paired comparisons; both additions were collateral
solves under one backbone at one seed. The retrieval cascade was
$8{,}854$ stored $\rightarrow$ $88$ retrieved, and retrieval reached $19$ of $240$
evaluation queries.

\textbf{Scope, stated plainly.} The backbones received $45\times$ fewer full-model updates
than the production models of Section~\ref{sec:tree} and were frozen thereafter, so this
compares adapters, not architectures. The $2{,}500$-update phase resampled only $753$
distinct sequence groups rather than the accumulated corpus. Conserved-credit routing was
\emph{not} tested: the direct-credit treatment found zero eligible receipts, because a
direct receipt requires the generating query's own target to be solved and such solves are
rare, so no route weight ever changed and no outcome claim is licensed. Finally, the
sampling contrast is not a novel mechanism: checking each program against all sequences is
hindsight experience replay in the sense of the original work~\cite{aliencoding} and is a
standing feature of that loop, so the control arm withheld an existing component rather than
the treatment adding one.

\section{Limitations and current status}

The tree multi-generation campaign has three inferential worlds at one medium configuration.
Its registered estimand is a total feedback-loop effect after generation 1, not a same-corpus
gradient comparison.  PC32's post-settle tied-operator update is sequential and
order-dependent.  The entropy evidence is observational at the checkpoint level, and two
settling-depth midpoints have one seed.  The generation-5 endpoint is not yet present in
this draft.

The recurrent version-0 effect is real for its exact implementation but does not establish
historical topology fidelity or sequence conditioning.  Version 1 corrects the known
architecture deviations and has retained discriminating oracles, but its first bounded
check departed from the registered method and provenance protocol.  Its initial C2
implementation cannot support a conditioning claim.  No version-1 feedback result and no
recurrent-PC result are yet claimed.

The most important positive conclusion is therefore also a constraint on interpretation.
Learning reliably produces useful program priors in both instruments.  The tree evidence
shows that lower training error can coexist with a worse search prior, and that sufficient
PC settling closes much but not all of the one-generation gap at substantial cost.  Whether
that gap compounds is a generation-5 question whose verification is still running.  Whether feedback and recurrent PC
survive in the NMT is a prospective program whose checker broker and graph oracles are part
of the scientific method, not post-processing details.

\section{Artifact-level reporting contract}

The final empirical release should generate tables from completion objects rather than
from hand-copied logs.  Each reported arm should expose at least:

\begin{itemize}
  \item content hashes for source, configuration, environment, baseline, target ledger,
        model, candidates, sidecar, checker chunks, aggregate outputs, and completion;
  \item training examples and tokens, optimizer updates, train/decode/check wall time,
        peak host and GPU memory, and retained storage;
  \item cumulative verified sequences, arm-own novelty, novelty beyond the prior paired
        union, conditional target hits, direct-full hits, harvested-prefix hits, hindsight
        hits, invalid and valid-prefix fractions, proposal occurrences, normalized
        emissions, canonical programs, and program/sequence length summaries;
  \item an explicit status for every expected phase: verified success, verified failure,
        incomplete attempt, superseded attempt, or absent.  Missing and incomplete phases are never numerical
        zeros.
\end{itemize}

records sequence ID, canonical program, source snapshot, world, arm, generation, model,
requested target, beam rank and score, direct-full versus harvested-prefix origin, checker
identity, and verification attempt.  This is sufficient to reproduce cumulative corpora
and to audit every distinction used in the paper.
